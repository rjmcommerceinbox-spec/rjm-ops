# RJM Commerce Ltd – rjm-ops (read this first, every session)

Private operations repo for RJM Commerce Ltd (Amazon UK FBA seller, Herbin/ExaClair stationery and gift sets). Owner: Rob Martin.

## Before doing anything
1. Read `DECISIONS.md` (dated decision log) and `GUARDRAILS.md`.
2. Check the claude.ai project "Exaclair And PL Research" docs and past chats before proposing work. Never redo or contradict a logged decision without flagging it to Rob.
3. Follow `weekly/WEEKLY_OPERATING_INSTRUCTION.md` for the Monday run.

## Hard rules
- Nothing that spends money, emails anyone, changes a live listing, changes prices or changes the accounts happens without Rob's explicit yes (approve by action number).
- SP-API keys live ONLY in the Mac Keychain. Never in this repo, email, docs or chat.
- Never delete files, branches or history. Archive instead (move to `archive/`).
- Every change is a commit with a clear message; every decision is logged in `DECISIONS.md`.
- Back up key files to Google Drive folder "RJM Ops Backup".
